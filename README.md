# SafeHer

SafeHer is a women’s safe route recommendation system for travellers within Dehradun, Uttarakhand.

## Objective

The project compares available routes using route distance and safety-related factors such as nearby police stations, hospitals, public places, and reported incidents. It recommends a comparatively safer route.

SafeHer does not book buses, cabs, autos, bikes, or other transport. The user independently chooses their travel mode after receiving a route recommendation.

## Main Features

- User registration and profile
- Guardian details
- Current location and destination input
- Graph-based route representation
- Dijkstra-based shortest route calculation
- Rule-based safety analysis
- Safety score and risk level
- Emergency services information
- Simulated SOS support
- Simulated guardian/location sharing
- Basic frontend interface

## Technologies
