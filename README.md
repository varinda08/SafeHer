# SafeHer

SafeHer is a women’s safe route recommendation system for Dehradun.

## Objective

The project compares available routes using route distance and safety-related factors such as police stations, hospitals, public places, and reported incidents. It recommends a comparatively safer route.

## Technologies

- C++
- Object-Oriented Programming
- Data Structures and Algorithms
- Graph
- Dijkstra's Algorithm
- Priority Queue / Min-Heap
- File Handling
- HTML, CSS and JavaScript
